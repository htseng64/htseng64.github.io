# Teaching Courses – Navigation & Maintenance Guide

本資料夾為本人教學網站（GitHub Pages）之課程總目錄。
本 README 僅供「教師本人／維護者」使用，學生不需閱讀。

---

## 🔑 使用原則（重要）

- ❌ 不使用 `/teaching/courses/` 作為對外入口（此層無 index.html，404 屬正常）
- ✅ 各課程皆有「各自入口資料夾」，請直接進入對應課程
- ✅ 所有對外連結（TronClass / 成果報告）**一律貼課程入口**
