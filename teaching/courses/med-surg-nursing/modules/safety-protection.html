安全與保護 Safety
保護個案免於身體傷害與環境危害的整體概念
  • 病人安全目標（IPSG）：正確辨識、有效溝通、用藥安全、手術安全、感染預防、跌倒預防
  • Joint Commission 醫療錯誤六大原因：溝通失誤、技術失誤、知識不足、評估失誤、監測失誤、系統缺陷
  • Swiss Cheese Model：每層防護均有漏洞；多層漏洞對齊時發生傷害
  • Root Cause Analysis（RCA）：發生後回溯根本原因分析
  • 不良事件通報制度：無懲罰文化；學習改善

感染過程 Infection Process
病原體在宿主體內建立、繁殖並引發疾病的過程
  • 感染鏈六環節：病原體→感染源→離開途徑→傳播方式→進入途徑→易感宿主
  • 感染期（Incubation）→前驅期（Prodromal）→症狀期→恢復期
  • 傳播途徑：接觸（直接/間接）、飛沫（>5μm）、空氣（<5μm）、媒介物、病媒
  • 宿主防禦：非特異性（皮膚黏膜、發炎反應、吞噬作用）vs 特異性（B/T細胞免疫）
  • 感染指標：發燒、WBC↑、CRP/PCT↑、局部紅腫熱痛

免疫系統 Immunity
身體辨識並消滅外來抗原及異常細胞的防禦系統
  • 先天免疫（非特異性）：物理屏障→發炎反應→自然殺手細胞（NK cell）
  • 後天免疫（特異性）：B細胞→抗體（體液免疫）；T細胞→細胞媒介免疫
  • CD4（T輔助細胞）正常值 500–1,500/μL；HIV感染時下降
  • 自體免疫：免疫系統攻擊自身組織（SLE、RA、MS）
  • 免疫缺乏：先天性 vs 後天性（HIV、化療、類固醇）→機會性感染

護理評估
Infection · Immune Function · Patient Safety Assessment
🌡️ 感染評估 全身/局部
  • 全身感染徵象：發燒（>38°C）、心搏過速、呼吸過速、白血球↑或↓
  • 敗血症（Sepsis）：SIRS＋確定或疑似感染；SOFA評分
  • qSOFA：呼吸>22次/分、GCS<15、收縮壓≤100 mmHg；≥2分懷疑敗血症
  • 局部感染：紅腫熱痛（rubor、tumor、calor、dolor）、功能喪失
  • 傷口評估：PUSH量表（大小、滲出液、組織型態）
  • 培養採集：血培養（發燒時盡早抽，給抗生素前）、尿液、痰、傷口
  • 血液檢查：CBC、CRP、Procalcitonin（PCT）、血培養×2套
  • 影像：胸部X光（肺炎）；CT（腹腔感染）
🔬 免疫功能評估 免疫指標
  • 白血球分類計數（Differential）：嗜中性球↑＝細菌感染；淋巴球↑＝病毒
  • 嗜中性球絕對值（ANC）：<500/μL＝嚴重嗜中性球低下→最高感染風險
  • CD4/CD8比值：正常>1；HIV感染時反轉（CD4↓、CD8↑）
  • 免疫球蛋白（IgG/IgM/IgA/IgE）：IgE↑＝過敏；IgM↑＝急性感染
  • 補體C3/C4：SLE活動期↓（消耗增加）
  • 自體抗體：ANA（狼瘡）、Anti-dsDNA（SLE特異）、RF（RA）、ANCA（血管炎）
  • 皮膚試驗：結核菌素（PPD/Mantoux）；陽性≥10mm硬結（免疫正常者）
  • HIV篩檢：ELISA→確認Western Blot；HIV RNA（病毒量）
🏥 隔離防護評估 感染管控
  • 標準防護措施（Standard Precautions）：所有病人均適用
  • 接觸隔離（Contact Precautions）：MRSA、VRE、艱難梭菌（C. diff）
  • 飛沫隔離（Droplet）：流感、百日咳、腦膜炎球菌、RSV；外科口罩
  • 空氣隔離（Airborne）：肺結核、水痘、麻疹；N95口罩、負壓單人房
  • 保護性隔離（Protective/Reverse）：嚴重免疫低下病人；正壓病房
  • 個人防護裝備（PPE）穿脫順序：穿（手套最後）；脫（手套最先）
  • 環境消毒：10:1漂白水溶液（1000 ppm）處理C. diff環境
💉 疫苗與預防 免疫預防
  • 主動免疫：接種疫苗，身體自行產生抗體（長效）
  • 被動免疫：注射免疫球蛋白（如IVIG、HBIg）；即效但短暫
  • 免疫低下病人：禁用活性減毒疫苗（如BCG、麻疹、水痘）
  • SLE病人建議接種：流感（每年）、肺炎鏈球菌（每5年）
  • HIV病人：可接種非活性疫苗；CD4>200/μL才可考慮部分活性疫苗
  • 器官移植後：移植前完成疫苗接種；移植後6–12個月再評估
  • 職業曝露後預防（PEP）：HIV針扎後2小時內開始抗病毒藥（28天）

手術部位感染SSI金黃葡萄球菌預防性抗生素（切皮前1小時）
VAP Bundle（呼吸器護理套組）
  • 床頭抬高30–45度（避免胃內容物逆流吸入）
  • 每日鎮靜中斷評估（Daily Sedation Vacation）
  • 每日評估脫離呼吸器可能性（Spontaneous Breathing Trial）
  • 消化性潰瘍預防（PPI/H₂ blocker）
  • DVT預防（彈性襪＋低分子肝素）
  • 每2–4小時口腔護理（CHX漱口液）
多重抗藥性菌（MDRO）
  • MRSA（甲氧苯青黴素抗藥性金黃葡萄球菌）：皮膚軟組織、肺炎；治療：Vancomycin / Daptomycin
  • VRE（萬古黴素抗藥性腸球菌）：UTI、菌血症；治療：Linezolid
  • CRE（碳青黴烯抗藥性腸桿菌科）：預後差；治療選項有限
  • 艱難梭菌（C. difficile）：抗生素使用後偽膜性大腸炎；水樣腹瀉；治療：Metronidazole / Vancomycin口服 / Fidaxomicin
  • MDRO護理：接觸隔離；專用器具；嚴格手部衛生（C. diff需肥皂水洗手，酒精無效）
⚠️C. diff 感染：酒精乾洗手無效！必須用肥皂水洗手（至少20秒）；使用稀釋漂白水（1:10）消毒環境；停用不必要的抗生素
敗血症 Sepsis
  • 定義：感染引起的威脅生命的器官功能障礙（SOFA≥2分）
  • 敗血性休克：需血管加壓素維持MAP≥65 mmHg＋乳酸>2 mmol/L
  • Hour-1 Bundle（第一小時集束治療）：
    ・測乳酸（Lactate）
    ・血培養（抗生素前）
    ・廣效抗生素給予
    ・低血壓或乳酸≥4者：30 mL/kg 晶體液快速輸注
    ・血管加壓素（若液體反應不佳）
  • 目標：MAP≥65 mmHg；尿量≥0.5 mL/kg/hr；乳酸清除
CAUTI與CLABSI預防護理
  • CAUTI預防：每日評估導尿管必要性（最有效措施）；保持集尿袋低於膀胱；勿讓尿管折疊；更換時無菌技術
  • CLABSI預防（插管時）：手部衛生→戴帽子口罩手套隔離衣→最大無菌屏障（Maximal Barrier Precautions）→CHX消毒皮膚→使用無菌覆蓋布
  • CLABSI預防（維護時）：每日CHX棉片消毒接頭；更換輸液組每72–96小時；觀察插入部位發紅腫脹
  • 洗手五大時機：接觸病人前、無菌操作前、接觸體液後、接觸病人後、接觸病人環境後

全身性紅斑性狼瘡
Systemic Lupus Erythematosus (SLE)
自體免疫
病因與流行病學
  • 自體免疫疾病：免疫複合體沉積→多器官損傷；抗雙股DNA抗體（Anti-dsDNA）為特異性指標
  • 好發：15–45歲育齡女性；女：男 ＝ 9：1；亞裔盛行率高
  • 誘發因素：紫外線、感染、壓力、藥物（hydralazine、procainamide→藥物性狼瘡）
  • 病程特點：緩解（remission）與惡化（flare）交替出現
診斷標準（ACR/EULAR 2019）
  • ANA（抗核抗體）陽性為入選條件（篩檢靈敏度99%）
  • 特異性指標：Anti-dsDNA ↑（活動期）、Anti-Sm（高特異）
  • 補體（C3/C4/CH50）活動期↓（被消耗）；ESR↑；CRP可正常
  • 累積分數≥10分可確診
臨床表徵（多系統）
  • 皮膚：蝴蝶形紅疹（butterfly rash / malar rash）——鼻樑橫跨兩頰；光敏性；盤狀紅疹；脫髮
  • 關節：多關節疼痛、晨間僵硬；通常不造成變形（不同於RA）
  • 腎臟：狼瘡性腎炎（Lupus Nephritis）——蛋白尿、血尿；最嚴重合併症之一
  • 血液：白血球↓（<4,000）、血小板↓（<100,000）、溶血性貧血
  • 心血管：心包炎、心肌炎；加速性動脈硬化（心血管死亡主因）
  • 神經：神經精神性狼瘡（NP-SLE）——頭痛、癲癇、精神症狀
  • 漿膜炎：胸膜炎、心包炎（胸痛）
治療
  • Hydroxychloroquine（HCQ，奎寧）：所有SLE病人基礎用藥；減少惡化頻率；眼底定期追蹤（視網膜毒性）
  • 輕度：NSAIDs（關節痛）；低劑量類固醇
  • 中重度：高劑量類固醇（Prednisolone）；甲基類固醇衝擊（IV MP）
  • 免疫抑制劑：Mycophenolate（MMF）、Azathioprine、Cyclophosphamide（重度腎炎）
  • 生物製劑：Belimumab（B淋巴細胞刺激因子抑制劑）
⚠️避免陽光照射：紫外線是SLE最重要誘發因子。外出：防曬係數SPF≥50、長袖衣物、帽子。避免午間11點–3點日照高峰
護理措施與衛教
  • 活動期：充分休息；減少日曬（紫外線→誘發惡化）；防曬衣物
  • 皮膚護理：觀察皮疹變化；溫和清潔劑；避免含香料產品
  • 腎功能監測：每日體重、血壓、I&O；尿蛋白定期追蹤
  • 感染預防：類固醇/免疫抑制劑使用→感染風險↑；接種流感/肺炎疫苗（活性減毒疫苗禁用）
  • 情緒支持：慢性病、外觀改變（脫髮/皮疹）→自我形象；焦慮憂鬱評估
  • 孕前諮詢：疾病穩定>6個月才可考慮懷孕；停用致畸胎藥物
  • 惡化警示：發燒（感染？惡化？）；新發蛋白尿；頭痛癲癇→立即就醫

類風濕性關節炎
Rheumatoid Arthritis (RA)
自體免疫
病因與臨床特徵
  • 慢性、全身性、對稱性炎症性關節疾病；滑膜增生→血管翳（pannus）→侵蝕軟骨骨頭
  • 好發：30–60歲女性（女：男 = 3：1）；HLA-DR4基因關聯
  • 診斷標誌：類風濕因子（RF）陽性；Anti-CCP（抗環瓜氨酸抗體）——特異性>95%、早期診斷
  • 對稱性關節炎：近端指間關節（PIP）、掌指關節（MCP）、腕關節最常受犯（遠端指間關節通常不侵犯←與退化性不同）
  • 晨間僵硬>60分鐘（退化性<30分鐘）是RA特徵
  • 關節外表徵：類風濕結節、乾眼/乾口（Sjögren's）、心肺病變、血管炎
特徵性關節變形
  • 天鵝頸畸形（Swan Neck Deformity）：PIP過伸展 + DIP屈曲
  • 鈕扣孔畸形（Boutonnière Deformity）：PIP屈曲 + DIP過伸展
  • 尺側偏移（Ulnar Deviation）：掌指關節向尺側偏斜
  • 槌狀指（Mallet Finger）：DIP屈曲固定
治療（DMARD為核心）
  • Methotrexate（MTX）：RA治療錨定藥（anchor drug）；每週一次；需補充葉酸
  • Hydroxychloroquine、Sulfasalazine（傳統DMARDs）
  • 生物製劑：抗TNF（Etanercept、Adalimumab）；IL-6抑制劑（Tocilizumab）
  • JAK抑制劑：Tofacitinib（口服）；小分子靶向治療
  • 類固醇：橋接治療（Bridge）；局部注射關節腔
護理措施
  • 疼痛與僵硬：晨間熱敷（減輕僵硬）；急性發作冰敷
  • 關節保護原則（Joint Protection）：使用大關節替代小關節；輔具使用
  • ROM運動：急性期被動，緩解期漸進主動；水中運動（減少負重）
  • 平衡休息與活動：過度活動加劇炎症；完全不動→肌肉萎縮
  • MTX副作用監測：噁心嘔吐、口腔炎、肝毒性（定期肝功能）、骨髓抑制
  • 生物製劑前篩檢：TB篩查（PPD/IGRA）；HBsAg；排除感染
  • 感染預防：生物製劑使用→免疫抑制；避免感染人群；疫苗（非活性）
💡RA vs SLE關節比較：RA = 對稱 + 近端指間/掌指關節 + 晨僵>60分 + 造成變形；SLE = 多關節痛 + 晨僵較短 + 通常不造成永久變形
日常生活適應衛教
  • 關節保護：開瓶使用輔助器；用肘部而非手指關關門
  • 工作改良：每工作20–30分鐘讓關節休息5分鐘
  • 居家環境：防滑浴墊、扶手、加高馬桶坐墊
  • 運動建議：游泳（水中關節負擔最輕）、太極拳、水中有氧
  • 體重控制：減輕負重關節負擔
  • 情緒：慢性疼痛→憂鬱高盛行率；評估PHQ-9
人類免疫缺陷病毒感染 / 愛滋病
HIV Infection / Acquired Immunodeficiency Syndrome (AIDS)
免疫缺乏
傳播與預防
  • 傳播途徑：血液、精液/陰道分泌物（性行為）、母嬰（垂直）
  • 不傳播途徑：握手、擁抱、共用餐具、咳嗽、唾液、蚊蟲叮咬
  • 針扎感染率：HIV約0.3%；HBV約30%；HCV約3%
  • 暴露後預防（PEP）：2小時內開始三合一抗病毒藥（28天）
  • 暴露前預防（PrEP）：高風險族群每日服用（Tenofovir/Emtricitabine）
  • 安全性行為：正確使用保險套（每次）；避免共用針具
病程分期
  • 急性HIV感染（2–4週）：流感樣症狀（發燒、淋巴腺腫、皮疹）；病毒量極高
  • 無症狀期（數年）：CD4緩慢下降；病毒持續複製
  • AIDS定義：CD4<200/μL 或出現AIDS定義疾病
機會性感染（CD4依程度）
CD4計數常見機會性感染
<500/μL復發性細菌性肺炎、帶狀疱疹
<200/μL肺囊蟲肺炎（PCP）——最常見機會性感染
<100/μL弓漿蟲腦炎（Toxoplasmosis）、隱球菌腦膜炎
<50/μL巨細胞病毒（CMV）視網膜炎、非結核分枝桿菌（MAC）
治療（ART）
  • 抗病毒治療（ART）：所有HIV病人均應治療；越早越好
  • 一線方案（Single Tablet Regimen）：整合酶抑制劑（如Dolutegravir）＋兩種核苷類似物
  • 治療目標：病毒量（HIV RNA）<50 copies/mL（偵測不到）；CD4恢復
  • U=U原則：Undetectable = Untransmittable（病毒量測不到＝不傳染）
護理措施
  • 標準防護措施：所有病人均適用；無需特殊隔離（除合併空氣傳播疾病如肺結核）
  • 口腔黏膜評估：鵝口瘡（Candida）常見；每班口腔護理
  • 皮膚評估：卡波西氏肉瘤（紫色病灶）；帶狀疱疹；皮膚乾燥
  • ART服藥順從性：每天同時間服藥；漏服率>5%→病毒突破及抗藥性
  • 營養：高熱量高蛋白；記錄體重；評估消耗症候群
  • 感染預防：避免生食（沙門氏菌）；避免接觸家禽糞便（隱球菌）
心理社會支持
  • 反汙名化：HIV是慢性可治療疾病；保護病人隱私（最高機密）
  • 告知議題：性伴侶告知法律規定；衛教不傳染行為
  • 情緒：確診後常見否認→憤怒→憂鬱；高自殺風險評估
  • 社會資源：愛之希望協會；疾管署HIV個管師制度
  • 職業曝露後護理人員支持：心理創傷支持；結果追蹤（6個月）
💡HIV病人不需特殊隔離（因HIV不透過空氣/接觸傳播）。若合併活動性肺結核→需空氣隔離。過度隔離反而造成汙名化與心理傷害

器官移植術後監測
  • 腎臟移植：每小時尿量（目標>1 mL/kg/hr）；血清肌酸酐趨勢；移植腎超音波
  • 肝臟移植：肝功能（AST/ALT/Bili）；膽汁引流管顏色（金黃＝正常）
  • 心臟移植：心電圖；心臟超音波（EF）；心內膜切片排斥評估
  • 排斥徵兆：發燒、器官功能惡化、移植部位疼痛腫脹→立即報告
免疫抑制治療
  • 三聯療法（標準）：鈣調磷酸酶抑制劑（Tacrolimus or Cyclosporine）＋抗代謝藥（MMF）＋類固醇
  • Tacrolimus（他克莫司）：治療範圍窄；需監測血中濃度（谷值5–15 ng/mL）；腎毒性；高血壓；新發糖尿病
  • Cyclosporine：同樣腎毒性；牙齦增生；多毛症（hypertrichosis）
  • Mycophenolate（MMF）：抑制淋巴球增殖；腸胃不適；骨髓抑制
  • mTOR抑制劑（Sirolimus）：抗排斥＋抗腫瘤
⚠️Tacrolimus 葡萄柚汁禁用！葡萄柚抑制CYP3A4→藥物濃度急升→毒性（腎毒性、神經毒性）。同理：Cyclosporine + 葡萄柚也禁忌
造血幹細胞移植（HSCT）
  • 適應症：白血病、多發性骨髓瘤、再生不良性貧血、重度地中海型貧血
  • 自體（Autologous）：自身幹細胞回輸；無排斥；復發率較高
  • 同種異體（Allogeneic）：供體（HLA配對）；排斥問題；移植物對抗白血病效應（GVL）
  • 移植物對抗宿主病（GvHD）：供體T細胞攻擊受者組織；急性（<100天）vs 慢性
  • 急性GvHD靶器官：皮膚（皮疹）→肝臟（黃疸）→腸胃道（嚴重腹瀉）
  • 植入成功指標：WBC上升（通常移植後10–14天）；ANC>500持續3天
保護性隔離護理（移植後）
  • 保護性隔離（正壓病房）：ANC<500/μL 嚴重免疫低下期
  • 訪客限制：感冒/感染者禁止探視；探視前洗手戴口罩
  • 飲食：無菌低菌飲食（熟食為主）；禁止生食、未洗蔬果、乳製品
  • 環境：新鮮花卉禁止（黴菌來源）；每日環境消毒
  • 口腔護理：每4小時一次（黏膜炎預防）；CHX漱口液
  • 皮膚護理：保濕；觀察GvHD皮疹（麻疹樣→融合→水泡）
  • 感染監測：每日體溫；ANC趨勢；培養；廣效預防性抗生素/抗黴菌

常見護理問題
Common Nursing Diagnoses (NANDA-I)
1
感染風險
Risk for Infection ／與免疫抑制、侵入性管路、中性球低下有關
  • 手部衛生：接觸病人前後（WHO五時機）
  • 侵入性管路：每日評估必要性；無菌換藥；觀察感染徵兆
  • ANC監測：<500/μL啟動保護性隔離；觀察發燒（>38°C即需培養並使用抗生素）
  • 避免感染源：生食禁止；訪客篩查；新鮮花卉禁止
  • 疫苗接種（非活性疫苗）；口腔衛生；皮膚完整性維護
2
急性/慢性疼痛
Pain ／與關節炎症、漿膜炎、GvHD有關
  • 每班NRS評估；記錄疼痛型態（早晨僵硬、活動後加劇）
  • RA晨間：熱敷10–20分鐘緩解僵硬；SLE漿膜炎→止痛藥
  • 關節保護技術；輔具使用；改良日常活動方式
  • 非藥物：水中運動（減少負重）；TENS；放鬆技巧
  • 藥物：NSAIDs（監測胃腸/腎）；類固醇關節注射
3
疲憊
Fatigue ／與貧血、慢性炎症、藥物副作用、疾病活動有關
  • 評估疲勞程度（VAS/BFI量表）；找出加重因素
  • 節省能量技術（Energy Conservation）：重要活動安排在精力好時段
  • 休息與活動交替：每活動30分鐘休息10分鐘
  • 貧血矯正：EPO、鐵劑、輸血依醫囑；監測Hb
  • 睡眠衛教：規律作息；疼痛控制好→睡眠品質↑
4
皮膚完整性受損
Impaired Skin Integrity ／與狼瘡皮疹、GvHD、免疫低下有關
  • SLE：每日觀察皮疹分布與變化；日曬後皮膚評估
  • 防曬：SPF≥50；避免午間高峰；長袖/帽子
  • 皮膚清潔：溫和無香料產品；溫水（勿熱水）
  • GvHD皮疹：觀察進展（點狀→融合→水泡）；保濕
  • 黏膜護理：口腔、眼睛（乾燥症）；人工淚液

知識缺乏
Deficient Knowledge ／與疾病自我照護、藥物、預防感染有關
  • SLE衛教：日曬預防；識別惡化徵兆（關節腫、蛋白尿、神經症狀）
  • RA衛教：關節保護技術；規律服用DMARDs；副作用監測
  • HIV衛教：U=U原則；服藥順從性；安全性行為
  • 移植衛教：服藥不中斷（排斥預防）；感染警示徵兆；飲食限制
  • 評估學習準備度；書面資料補充；家屬同步衛教
6
體液容積不足風險
Risk for Deficient Fluid Volume ／與GvHD腸道、腎臟損傷、發燒有關
  • 每日體重（發燒期每班）；嚴密I&O記錄
  • GvHD腸道型：記錄腹瀉量（每次）；電解質監測；靜脈補液
  • 發燒：每升高1°C不顯性失水增加約200 mL/day；增加補液
  • 腎臟移植術後：每小時尿量<30 mL/hr→立即通知；排除排斥或血栓
  • 皮膚彈性評估；口腔黏膜；血壓趨勢

身體意象紊亂
Disturbed Body Image ／與皮疹脫髮、類固醇副作用、器官移植有關

  • 類固醇：月亮臉、水牛肩、妊娠紋、體重增加

  • 遮蓋技巧：假髮、帽子、防曬化妝品（不含香料）

社交孤立
Social Isolation ／與長期隔離、HIV汙名化、疾病限制社交有關

  • 移植病人：隔離必要性衛教；鼓勵視訊與家人保持聯繫
  • HIV：保護隱私；去汙名化；告知不傳染途徑
  • 安排社工、心理師會談；宗教/靈性支持
  • 出院計畫：社區資源、病友支持團體、返診計畫

Q1
此個案符合敗血症診斷嗎？計算qSOFA並分析
qSOFA評分：
• 呼吸>22次/分：✓（24次） = 1分
• 收縮壓≤100 mmHg：✓（94 mmHg） = 1分
• GCS<15：需評估（資料未提及，假設清醒）= 0分
• qSOFA ≥ 2 → 懷疑敗血症

敗血症確認：
• 確定感染來源：CLABSI（MRSA導管相關菌血症）
• 乳酸 3.8 mmol/L（>2）+ 需升壓藥 → 敗血性休克

Hour-1 Bundle立即啟動：
① 已測乳酸（3.8 mmol/L）✓
② 血培養兩套（立即，抗生素前）
③ 廣效抗生素（考慮MRSA：Vancomycin IV）
④ 30 mL/kg晶體液快速輸注（30kg×30=900 mL，15–30分鐘內）
⑤ 血管加壓素（Norepinephrine）：維持MAP≥65 mmHg
Q2
分析此次CLABSI的可能原因，制定預防護理計畫
CLABSI危險因素分析：
• 化療→嚴重骨髓抑制（ANC<100）→免疫防禦力極低
• 導管留置第7天→時間越長風險越高
• 導管部位感染徵兆（發紅、膿性滲出）→局部感染已發生
• 可能護理缺失：更換接頭未完全無菌；皮膚消毒不確實

處置：立即移除感染導管（明確感染源時）；另建新的血管通路

CLABSI預防護理計畫：
插管時（Insertion Bundle）：
→ 最大無菌屏障（帽子＋口罩＋無菌手套＋隔離衣＋大型無菌覆蓋布）
→ CHX葡萄糖酸（2%）消毒皮膚，乾燥後再插管
→ 鎖骨下靜脈優先（感染率最低）

維護時（Maintenance Bundle）：
→ 每日CHX棉片消毒接頭端（Scrub the Hub，15秒）
→ 每日評估導管必要性並記錄→不需要立即移除
→ 觀察插入部位每班；透明敷料每7天或潮溼時更換
→ 更換輸液組：一般72–96小時；血製品/脂肪乳劑24小時
Q3
個案ANC < 100/mm³，需要採取哪些特殊護理措施？
嚴重嗜中性球低下護理（ANC < 500/μL，尤其 <100/μL）：

隔離環境（保護性隔離）：
• 安置於正壓單人病室（過濾空氣，防外界感染進入）
• 訪客限制：感冒/感染者禁入；進入需戴外科口罩＋洗手
• 植栽、生鮮花卉禁止（黴菌來源）

感染監測：
• 發燒（>38°C）即為緊急：立即血培養（至少兩套）＋廣效抗生素，無須等培養結果
• 注意：ANC<500時，典型感染徵兆（膿、炎症）可能缺席！
• 每日ANC；PCT/CRP趨勢

飲食：低菌飲食（熟食；不生食；水果去皮或煮熟）
口腔護理：每4小時一次；觀察鵝口瘡、黏膜潰瘍
皮膚：溫和清潔；避免肛溫測量（肛門黏膜損傷→菌血症）；避免肛門指診

Q2
制定此個案的護理措施，包含狼瘡性腎炎的監測重點
急性護理措施：

① 皮膚護理
→ 絕對臥床休息（急性期）；避免任何光照
→ 蝴蝶形皮疹：溫和無香料清潔劑；避免抓癢；評估進展

② 狼瘡性腎炎監測
→ 每日體重（早晨空腹）；每班I&O；下肢水腫分級
→ 血壓嚴格監控（目標<130/80）→腎臟保護
→ 24小時尿蛋白定期追蹤；GFR計算（Cr趨勢）
→ 限鈉（<2g/天）；液體依腎功能調整

③ 貧血/血小板低下
→ 監測Hb/Plt趨勢；活動安全（避免跌倒出血）
→ 嚴重血小板低下（<50,000）：避免肌肉注射；軟毛牙刷

④ 藥物護理
→ 依醫囑增加類固醇（活動期）；監測血糖、血壓（類固醇副作用）
→ 免疫抑制劑（Mycophenolate / Cyclophosphamide for 腎炎）
Q3
此個案為育齡女性，如何提供孕前諮詢及長期衛教？
SLE育齡女性衛教：

懷孕諮詢：
• 疾病需穩定≥6個月（無器官惡化、低劑量維持藥物）才可考慮懷孕
• 目前狀況（活動性腎炎）：不宜懷孕；控制疾病後再討論
• 懷孕期SLE：高風險（子癲前症、流產、早產）；需高危妊娠追蹤
• 藥物調整：Hydroxychloroquine可繼續（安全）；Mycophenolate必須停用（致畸胎）；改Azathioprine

長期自我管理衛教：
→ 防曬：每天外出SPF≥50、帽子、長袖（最重要！）
→ 識別惡化徵兆：蛋白尿增加、新發皮疹、關節腫、發燒→立即就醫
→ 規律追蹤：每3–6個月Anti-dsDNA、補體、腎功能
→ 壓力管理：瑜伽、冥想；充足睡眠
→ 感染預防：免疫低下時避免人群；接種流感/肺炎疫苗（非活性）
→ 切勿自行停藥（緩解期仍需維持基礎藥物）

分析此個案的臨床表徵，診斷為何？嚴重度如何？
診斷：急性移植物對抗宿主病（Acute GvHD）

• 皮膚：軀幹紅疹→評估體表面積（BSA）受累% → Grade定義
• 肝臟：Total Bilirubin 4.2 mg/dL → Grade II（2–3 mg/dL = GrI，3–6 = GrII）
• 腸胃道：腹瀉1,500 mL/day → Grade III（500–1000=GrI，1000-1500=GrII，>1500=GrIII）

Q2
腸胃道GvHD護理：如何處理嚴重腹瀉及液體流失？
腸胃道GvHD腹瀉護理：

① 液體補充（最優先）
→ 腹瀉1,500 mL/day + 發燒不顯性失水 → 嚴重脫水風險
→ 精確記錄每次腹瀉量（量杯測量，非主觀估計）
→ 靜脈補液：依I&O補充；電解質（K⁺、Na⁺、Mg²⁺）監測每日
→ 體重每日（最敏感液體狀態指標）

② 腸道休息（NPO或低殘渣飲食）
→ 重度GvHD（Grade III）：NPO；完全靜脈營養（TPN）
→ 逐漸緩解後：清流質→低纖低乳糖→漸進正常

③ 肛周皮膚護理
→ 每次腹瀉後溫水清潔；皮膚保護霜（Zinc oxide）
→ 評估失禁相關性皮膚炎（IAD）；防水敷料保護

④ 感染排除
→ 大便培養排除C. diff等感染（GvHD與感染腹瀉需鑑別）
→ CMV病毒血症（移植後常見）：PCR監測

Q1
說明PCP的護理重點，此個案為何停藥？如何處理
PCP（肺囊蟲肺炎）護理：
• 治療：TMP-SMX（Bactrim）高劑量×21天；PaO₂<70→加Prednisolone減輕炎症
• 呼吸護理：高流量氧氣（面罩）；SpO₂目標>92%；必要時HFNC或機械通氣
• 監測：呼吸功能趨勢（RR、SpO₂）；每日胸部X光進展；LDH（治療反應指標）

停藥原因探索：
面對ART中斷，護理師應不帶評判地探索原因：
→ 藥物副作用難以忍受？（可更換方案）
→ 汙名化恐懼（他人發現服藥）？
→ 憂鬱、否認疾病？
→ 經濟困難？（台灣HIV藥物全部由健保/疾管署全額補助）
→ 遺忘或生活作息改變？

重啟ART時機：
• PCP治療2週後重啟ART（過早→免疫重建炎症症候群IRIS）
• 衛教：規律服藥的重要性；U=U原則；HIV個管師資源
Q2
針對此個案制定衛教計畫，協助其重建服藥順從性
ART服藥順從性衛教計畫：

為什麼重要（說明後果）：
→ 停藥→病毒量↑→CD4↓→免疫崩潰→機會性感染（如此次PCP）→可能死亡
→ 不規律服藥→病毒突破→抗藥性產生→未來選擇減少

現代ART的好消息（去汙名化）：
→ 每天一顆（Single Tablet Regimen）；副作用已大幅減少
→ U=U：病毒量測不到→不傳染（重要動力）
→ 台灣HIV藥物全額補助，不需自費

提升順從性策略：
→ 找出障礙並個別化解決（副作用→換藥；遺忘→鬧鐘/藥盒）
→ HIV個管師：長期追蹤、心理支持、協助解決問題
→ Peer support（同儕支持）：已治療成功的HIV病友分享
→ 每次回診：「沒有評判的問診環境」

護理師態度：
→ 不批評、不評判停藥行為；以好奇心問「是什麼讓服藥變得困難？」
→ 保護絕對隱私；創造安全說話環境
Q3
護理師在為此個案進行侵入性操作時，針扎風險的標準處置流程是什麼？
針扎後處理流程：

① 立即傷口處理
→ 立即用肥皂水沖洗至少5分鐘；自然擠出少許血液（勿用嘴吸）
→ 消毒劑塗抹（70%酒精或碘伏）

② 立即報告
→ 通知主管；填寫針扎事件報告；記錄時間、部位、操作類型

③ 評估風險（此案高風險）
→ 來源：HIV陽性＋病毒量85萬 copies/mL（高傳染性）→高風險暴露
→ 傷口類型（深刺？空心針？）

④ 暴露後預防（PEP）
→ 2小時內開始PEP（最晚72小時內）
→ 三合一ART藥物（如TDF/FTC + RAL或DTG）連續28天
→ HIV傳染率：0.3%（針扎）→PEP可降低約80%

⑤ 追蹤
→ HIV篩檢：基線（立即）、4週、8週、12週、6個月
→ 心理支持：提供焦慮諮詢；維護隱私

預防勝於治療：使用安全針具、雙層手套、操作後立即丟棄針頭（勿回套）
