使用說明 How to Use
📱 網頁功能
  • 左側導覽列可點擊「☰」按鈕收合/展開
  • 桌機模式：收合後主內容自動撐滿；狀態自動記憶
  • 手機模式：側欄變為滑入式抽屜，點空白處關閉
  • 各疾病/主題分頁點擊即切換，無需重新載入
  • 案例解析按鈕逐題展開，適合課前自學與課後複習
  • 右下角「↑」按鈕可快速回到頁頂
📚 學習建議
  • 建議依序閱讀：先核心概念 → 護理評估 → 疾病介紹 → 護理問題 → 案例分析
  • 案例分析建議先自行作答，再展開解析對照
  • 搭配教科書使用：黑底網頁為精要整理，細節請參照原文
  • 全人案例演練建議最後閱讀，整合所有單元概念
  • 本教材以自學為目標，每單元估計需要2–3小時
  • 內容僅供學術教育用途，臨床決策請遵循醫院規範
