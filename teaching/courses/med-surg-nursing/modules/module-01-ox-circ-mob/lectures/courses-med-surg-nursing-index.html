課程運作模型（固定模板，之後可複製到各單元）

  1. Pre（課前）：短測（5–8題）＋看 1 個情境片段（Scene）
  2. In-class（課中）：Unfolding case（逐步揭露）＋Gate（拖曳/判讀/排序）＋老師 60–90 秒收斂
  3. Post（課後）：同題 Post-test（可比對 Pre/Post）＋反思一句話（短答）

本站目前先用 localStorage 存進度；之後接 Supabase 才能跨裝置、跨教室統計。

Modules（教材入口）

徽章為「本機」進度概覽：綠＝已有完成紀錄；黃＝進行中；紅＝尚未開始。
投影時可點整張卡片放大（Esc 退出）。

老師維護（你之後只要改這裡）

✅ 新增一個章節/單元時，你只要在 JS 的 MODULES 陣列加一行：

{ slug:"module-02-xxx", title:"Module 02｜...", href:"./modules/module-02-xxx/index.html", unitPrefix:"unit-02-xxx" }

slug＝資料夾名稱（網址的一部分），建議：小寫英數＋連字號（例如 module-01-ox-circ-mob）。
