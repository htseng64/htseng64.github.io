Module 00｜Foundation

課程導入 × 全人評估 × 操作規則 必修 只上一次 後面模組都用同一套

這門課「怎麼上」

  1. 不是一直聽課：你會一直被要求「判斷、選擇、排序」
  2. 每個單元是解謎：Scene → Puzzle → Gate → 下一幕
  3. 老師不是一直講：只在你卡關時給 30–90 秒重點
  4. 同一題會做兩次：Pre-test（課前）＋Post-test（課後）

這不是考你記憶力，是訓練你「臨床思考順序」。

什麼是「全人評估」？

全人評估不是 checklist，而是回答三個問題：

  1. 這個病人現在最不安全的是什麼？
  2. 問題來自哪一個系統（氧合／循環／活動／心理…）
  3. 我現在的護理行動，會不會讓他更安全？

之後每一個 Scene，你都會被要求回到這三句。

作答方式與評分原則

  • ✔ 可重做（重點是思考，不是一次對）
  • ✔ 有理由比選項重要
  • ✔ Pre/Post 比較「進步幅度」
  • ✘ 只背答案、不看線索 → 分數會低

老師會看你「怎麼想」，不是只看你「選什麼」。

你會用到的工具

  • TronClass：繳交、測驗、成績
  • GitHub / 網頁教材：情境、解謎、互動
  • Notion：補充資料、整理思考（老師提供）

不需要寫程式，你只要「會點、會想、會回應」。
