🫁 Part A：氧合與循環護理 整合氧合・安全・感覺知覺
1
王阿伯夜間拔除BiPAP面罩及點滴管路，應如何安全介入？
評估：可能的夜間躁動原因（THINK框架）
→ 低氧血症（SpO₂↓）→ 大腦缺氧 → 躁動
→ 夜間日落症候群（Sundowning）：失智症特徵
→ BiPAP面罩不適（幽閉恐懼感）
→ 疼痛未被表達（失智者疼痛評估困難）
→ 譫妄（ICU/住院環境誘發）

非藥物優先介入（失智/譫妄第一線）：
• 先排查低氧：確認SpO₂；調整BiPAP參數；是否有CO₂滯留
• 熟悉的陪伴：請女兒在場；熟悉的聲音/氣味（家的感覺）
• 定向導引：燈光充足；時鐘/日曆可見；簡單重複告知「阿伯，你在醫院，女兒在旁邊」
• 減少夜間護理操作干擾；集中操作
• 舒適：確認是否因管路不適 → 評估是否需要管路

管路安全：
• 不使用身體約束（加重躁動、增加傷害）；使用防抓手套（軟性）需短暫評估
• BiPAP更換為鼻罩式（較不易拔除）
• 評估每條管路的必要性：能撤除的盡早撤除

藥物（非藥物無效時）：
低劑量Haloperidol 0.25–0.5mg；避免苯二氮類（加重失智/譫妄）
2
COPD合併心衰竭的氧氣給予有何特殊考量？
COPD + 心衰竭的氧療衝突：

COPD考量（限制性氧療）：
→ 慢性CO₂滯留病人以低血氧驅動呼吸
→ 給太高氧濃度 → 抑制缺氧驅力 → CO₂麻醉
→ 目標 SaO₂ 88–92%，PaO₂ 50–60 mmHg

心衰竭考量：
→ 嚴重肺水腫需要更高氧（目標 SaO₂ >94%）
→ 矛盾！

臨床決策：
→ 優先以ABG（動脈血液氣體分析）指導：若PaCO₂已升高（>45）→ COPD考量優先
→ 若ABG正常或PaCO₂正常 → 心衰竭處理，可稍高氧療
→ Venturi Mask（文丘里面罩）：精準控制FiO₂（24%、28%、31%）
→ 嚴重呼衰：BiPAP同時解決兩者（支援通氣 + 改善心臟後負荷）
→ 監測：每4–6小時ABG；氧療調整依數值

王阿伯說「活夠了」，如何評估並進行預立醫療討論？
「活夠了」的多層意涵評估：

→ 可能是：疲憊感（不等於自殺意念）、接受生命有限、對照護負擔的顧慮（不想拖累女兒）
→ 需要進一步探索：「阿伯，您說活夠了，可以告訴我，您最擔心的是什麼嗎？」

認知障礙與決策能力評估：
→ MMSE 22分（輕度）：目前大多數時候仍有決策能力
→ 趁清醒時進行預立醫療討論

ACP（預立照護計畫）討論方向：
→ 「如果呼吸又變很差，您希望我們怎麼做？」
→ 了解對急救（CPR）、插管、人工呼吸器的意願
→ 台灣《病人自主權利法》：本人可預立醫療決定（AD）
→ 若無法完成AD：ACP家庭會議——讓家人了解病人已表達的偏好

靈性評估（FICA）：
→ 了解道教信仰對死亡的觀點；有無特定儀式需求
→ 有無未竟之事、想見的人

🦠 Part A：FN緊急處置與感染管控 整合腫瘤・安全・感染
1
懷疑CLABSI，1小時內的緊急護理處置步驟
FN + 疑似CLABSI 緊急處置（Hour-1 Bundle）：

① 立即血培養（抗生素前）：
→ PORT-A blood culture（1套）+ 周邊靜脈（1套）
→ 同步送：CBC diff、CMP、乳酸、尿液培養、PORT-A局部分泌物培養

② 抗生素（1小時內給）：
→ 廣效抗生素覆蓋MRSA：Vancomycin IV + Piperacillin/Tazobactam
→ PORT-A紅腫懷疑CLABSI → Vancomycin是必要的

③ PORT-A評估：
→ 觀察插入部位：紅腫範圍、滲出物
→ 是否需要移除：明確CLABSI時，需移除PORT-A
→ 移除前先確保建立其他靜脈通路

④ 靜脈液體（低血壓處理）：
→ BP 102/68 + 心率112 → 補液晶體液 500–1000 mL評估反應

⑤ 保護性隔離（ANC 180/μL）：
→ 正壓單人病室；訪客限制；低菌飲食

林太太說「化療快撐不下去了」，如何進行治療性溝通與心理評估？
治療性溝通（語言限制的特殊考量）：

溝通策略（中文有限）：
→ 使用簡單、清晰的中文；一次一個概念
→ 若需要：申請馬來語/英語電話翻譯
→ 圖示輔助（疼痛臉譜；症狀圖示）

回應「撐不下去了」（NURSE模式）：
→ N（命名）：「我聽到您說很累，這段時間真的太辛苦了」
→ U（理解）：「8kg沒了，又一直進不了食，還在擔心孩子……」
→ R（尊重）：「您撐到第四週期，真的很勇敢」
→ S（支持）：「我們現在的目標是先讓您舒服一些，再一起想辦法」
→ E（探索）：「您說撐不下去——您最擔心的是什麼？是身體的痛苦，還是擔心治療繼續？」

PHQ-9 12分的後續：
→ 第9題評估（自傷意念）
→ 轉介心理師（中文溝通可行時）
→ 告知腫瘤科醫師：評估是否調整化療方案（症狀管理優先）

表達性失語症病人（陳先生）的溝通護理計畫
表達性失語症溝通護理：

評估：
→ 表達性（Broca's）失語：理解能力相對保留；說話困難但懂你說的
→ 核心原則：不急、不代為說話、尊重其嘗試

溝通輔助工具：
→ 溝通板（Communication Board）：圖卡＋文字；是/否卡
→ 書寫板（健側左手，若有訓練）
→ AAC（擴大替代溝通）：評估智慧型溝通APP（語言治療師建議）

護理師溝通技巧：
→ 面對面；眼神接觸；一次一個訊息
→ 是/否問題：「您痛嗎？（點頭=是）」
→ 給充分時間：不催促；填補空白讓他嘗試
→ 正確做法：「我知道您在努力說，請繼續……」
→ 錯誤做法：「我知道你要說什麼！是這個嗎？」（不讓他練習）

家屬衛教：
→ 教家屬溝通技巧；避免「他就是不努力」的誤解
→ 語言治療師會議：家屬一起學習居家溝通策略

陳先生拒絕職能治療，如何評估並介入？（動機式晤談）
拒絕治療的心理分析：

→ PHQ-9 18分 → 重度憂鬱 → 動機/精力不足是憂鬱的核心症狀，非不合作
→ 「我廢了」 → 習得無助感（Learned Helplessness）
→ 工程師身份喪失 → 「復健有什麼用？」的虛無感

動機式晤談（MI）溝通策略：
（注意：失語症病人需配合溝通板/書寫）
→ 開放性探索（溝通板）：「您不想去OT，是因為覺得太累？還是覺得沒有意義？」
→ 肯定（Affirm）：「您在這麼艱難的情況下，還願意告訴我您的感受，這需要很大的勇氣」
→ 探索矛盾心理：「您說覺得沒用了——但您也一直在用溝通板回答我。這需要努力的」
→ 強化改變對話：「如果情況進步一點點，對您最重要的是什麼？（溝通板）能陪孩子？回到工作？」

憂鬱治療同步介入：
→ 精神科會診（PHQ-9 18分，重度）
→ SSRI考慮（中風後憂鬱治療有實證）
→ 心理師：CBT適應版（失語症病人）

制定黃奶奶的安寧疼痛管理計畫（WHO三階梯 + 末期特殊考量）

現況評估：NRS 7（重度）→ 直接第三階梯（強鴉片類）

2
長子要求積極治療，如何進行家庭會議並處理衝突？
家庭會議設計：

目的：不是說服長子「同意安寧」，而是協助家庭在尊重奶奶意願的基礎上達成共識

參與者：三位子女（共同在場）+ 醫師 + 護理師 + 社工

護理師角色：中立協調者；確保奶奶的聲音被聽見

議程結構：
① 告知目前病況（醫師說明預後）
② 回到奶奶的意願：「媽媽已簽署DNR和安寧同意書，這是她自己的決定」
③ 探索長子的擔憂：「您說不點滴是餓死媽媽——我想了解您的顧慮……」
→ 可能的深層恐懼：愧疚感（不孝？）；對醫療放棄的誤解
④ 重新定義「積極」：「積極照顧不一定是積極治療——現在積極控制疼痛就是積極的照顧」
⑤ 達成共識：焦點轉向「如何讓媽媽最後的時間有尊嚴、不痛苦」

⚠️ 若長子仍堅持，可邀請醫療倫理委員會介入。核心原則：有決策能力時簽署的DNR/安寧同意書，子女不能推翻
3
奶奶說看到「先生來接我」——如何回應？並如何協助四道人生？
死前視見（Nearing Death Awareness）護理回應：

對奶奶：
→ 不否認：不說「那是幻覺，公公不在」
→ 溫和回應（台語）：「奶奶，公公來接您了，您先生還是那麼疼您」
→ 傾聽她描述；允許她與「視見」互動
→ 這是珍貴的靈性時刻；創造安靜的陪伴空間

對家屬（提前衛教）：
→ 「這是臨終正常現象，研究已記錄許多案例。她看到的是安慰的——不是痛苦的」
→ 「這可能代表她快要離開了。這是珍貴的四道時機」

四道人生的協助：

道謝：協助子女對奶奶說「媽媽，謝謝您養育我們」
道愛：「媽媽，我們愛您，您一輩子都是好媽媽」
道歉：長子可以說「媽媽，我知道我之前太堅持了，我對不起您」→ 這個化解對雙方都有療癒作用
道別：「媽媽，您可以放心去了，我們會照顧好彼此。公公在等您」

佛教靈性支持：
→ 安排法師/院牧探訪（奶奶意願）
→ 助念機（輕聲播放）
→ 家屬一同加入助念（即使不是佛教徒）——是對奶奶的愛
4
護理師在長期照顧這類末期病人後，如何照顧自己的心理健康？
護理師靈性自我照護（Nurse Self-Care）：

承認並接受情緒：
→ 奶奶這樣的病人，護理師會產生情感連結 → 往生後感到悲傷是正常且健康的
→ 不要說「我是護理師，不應該哭」

往生後的情緒處理：
→ 與同事短暫分享：「奶奶今天走了，她走得很平靜」
→ 儀式感：默哀；在護理記錄上寫下一句對奶奶的送別
→ 若與病人有深度情感連結：安排正式的同儕Debriefing

自我照護日常實踐：
→ 下班儀式：換衣→深呼吸→有意識地「換角色」
→ 正念：把情緒帶回家 vs 讓情緒在家中消化
→ 社交：與非醫療圈朋友的「正常生活」接觸

機構支持：
