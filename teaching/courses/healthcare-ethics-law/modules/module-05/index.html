Module 05｜Tarasoff 互動情境學習（入口）

請依上課情境選擇：課堂即時投票（Supabase） 或 離線作業（匯出 JSON）
老師用學生用同一入口
✅ 建議做法：兩個版本都放在同一資料夾，讓你不需要每次改連結。
檔名建議：live.html（即時版）、local.html（離線版）。
即時版全班統計
A. 課堂投影：房間碼＋即時統計（Supabase）
適合：全班手機投票 → 右側長條圖即時更新。
使用前：請先在頁面右側輸入房間碼（例如 ETHICS-2026-01）。
離線版免資料庫
B. 遠距自學：個人作答＋匯出 JSON（離線）
適合：學生在家完成 Scenes、六模型、觸發點、反思。
交作業：按「匯出 JSON」→ 貼到 TronClass 作業區或表單。
小提醒
若你現在用的是本機路徑（C:\ / D:\）開檔，功能有時會受瀏覽器限制；上傳到 GitHub Pages 後最穩。
