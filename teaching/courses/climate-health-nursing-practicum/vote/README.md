## GitHub Pages 上傳方式
1. 解壓縮 ZIP。
2. 將整個資料夾內容放到您的 GitHub repository：
   teaching/courses/climate-health-nursing-practicum/vote/
3. 修改 index.html：
   將 PASTE_YOUR_GOOGLE_FORM_URL_HERE 換成您的 Google Form 填答網址。
4. Commit。
5. Push。
6. 網址約為：
   https://htseng64.github.io/teaching/courses/climate-health-nursing-practicum/vote/
